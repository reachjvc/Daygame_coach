Beliefs exercise

Belief test

A belief like “I need it to unwind” runs the habit long after the body is clear. You don’t argue it away. You write it down, find something else you already believe, and then test both in real life.

  1. The old belief. Write it the way it sounds in your head. Rate how true it feels.
  2. What is also true. Write something you also genuinely believe. Not a slogan: something you could defend to a friend.
  3. The test. One thing you will do this week. Before you do it, write what each belief says will happen.
  4. The result. Do it. Write what happened. Rate both beliefs again.
